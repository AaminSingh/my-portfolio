# Aamin Simmi Singh – Developer Portfolio

A next-generation Next.js portfolio featuring a sleek **Hacker/Developer Aesthetic**, **4 Dynamic Theme Palettes**, **Bright Spark Cursor**, **System Deployments Grid**, **Verified Certificates Arsenal**, and a **Content Admin Dashboard**.

## 🌟 Key Features

- **4 Dynamic Theme Palettes**:
  - 💜 **Cyber Purple**: Deep violet dark mode (`#0a0a0d`)
  - 💚 **Neon Matrix**: Electric mint green dark mode (`#080c0a`)
  - 💙 **Hyper Blue**: Oceanic cyan & electric blue dark mode (`#060b14`)
  - ☀️ **Clean Light**: High-contrast minimalist white theme (`#f8fafc`) with deep purple typography
- **Bright Spark Cursor**: Custom particle spark trail cursor with theme-reactive glowing trail.
- **System Deployments Grid**: Showcasing production applications (*PRAMAAN*, *RAG Chatbot*, *KAVACH Safety*, *AI-Medical Assistant*).
- **Verified Credentials Page**: Responsive grid of certified accomplishments (*Oracle AI*, *MongoDB*, *IBM*, *Tata*, *Deloitte*).
- **Tabbed Content Admin Dashboard**: Full CRUD interface for projects, certificates, blogs, and PDF resume replacement.
- **NoSQL & Cloud Storage Integration**: MongoDB/Firebase DB and AWS S3/Firebase storage abstraction with JSON fallback.

## 🚀 Tech Stack

- **Framework**: Next.js (React 18/19)
- **Styling**: TailwindCSS & Custom CSS Variables
- **Animations**: GSAP & Framer Motion
- **Database / API**: Next.js Serverless API routes with NoSQL DB integration
